## 🚀 立即开始

```bash
# 安装 OpenClaw
npm install -g openclaw

# 初始化配置
openclaw init

# 启动你的助手
openclaw gateway start
```

**就这么简单！** 3步即可拥有你的AI助手。

## ❓ 常见问题

### Q: OpenClaw 是免费的吗？
A: 核心功能完全免费开源。部分高级功能需要付费，但基础使用没有任何限制。

### Q: 需要编程基础吗？
A: 基本使用不需要编程。如果你想自定义技能，需要一定的 JavaScript/TypeScript 基础。

### Q: 支持哪些 AI 模型？
A: 支持 GPT-4、Claude、Gemini、本地模型等多种模型，你可以自由选择。

### Q: 数据安全吗？
A: 非常安全！OpenClaw 支持本地运行，数据不会发送到第三方。你也可以选择云端部署。

### Q: 可以在手机上用吗？
A: 可以！通过 Telegram、Discord、微信等平台，手机上也能随时使用你的 AI 助手。
