# 实例教程

通过实际案例学习如何使用 OpenClaw 解决问题。

## 快速案例

### 案例 1：自动化文档整理

**场景**：自动整理工作区的文档文件

**实现方式**：
```bash
# 让 AI 助手执行
"帮我把 ~/Documents 目录下的所有 PDF 文件按年份分类到不同的文件夹中"
```

**助手会**：
1. 扫描目录找到所有 PDF 文件
2. 提取文件的创建或修改日期
3. 按年份创建文件夹
4. 移动文件到对应文件夹

### 案例 2：电商数据分析

**场景**：分析销售数据并生成报告

**数据文件** `sales.csv`：
```csv
date,product,price,quantity

2024-01-02,Product B,149.99,5
```

**对话示例**：
```
你：分析 sales.csv，告诉我最畅销的产品和总收入
助手：
✓ 读取了 sales.csv
✓ 分析了销售数据

最畅销产品：
- Product A：10 件
- Product B：5 件

总收入：¥1,749.85
```

### 案例 4：网页内容监控

**场景**：监控特定网页的更新

**配置定时任务**：
```yaml
schedules:
  - name: monitor-website
    cron: "*/30 * * * *"  # 每30分钟
    message: "检查 https://example.com 是否有更新"
```

**助手会**：
- 每30分钟检查网页
- 对比上次的内容
- 如果有更新则通知你

### 案例 11：构建个人知识助手

**需求**：
- 自动整理笔记
- 快速检索信息
- 生成学习总结

**实现**：

```yaml
# config.yml
agents:
  - name: knowledge-assistant
    model: gpt-4
    tools:
      - file
      - web
    memory:
      enabled: true
    skills:
      - summarizer
      - organizer
```

**使用方式**：
```
你：整理我的学习笔记
```

### 案例 12：电商自动化助手

**需求**：
- 监控竞品价格
- 生成营销内容
- 分析销售数据

**实现**：

```yaml
schedules:
  - name: price-monitor
    cron: "0 */6 * * *"

  - name: sales-report
    cron: "0 18 * * *"

```

**使用方式**：
```
你：监控这些产品的价格
助手：请提供产品列表...

助手：✓ 已开始监控
✓ 每6小时检查一次

如有价格变化，我会立即通知你。
```

## 最佳实践

### 1. 明确需求
在让 AI 助手执行任务前，清晰描述你的需求

### 2. 分步执行
对于复杂任务，分解为多个小步骤

### 3. 提供上下文
提供足够的背景信息，帮助 AI 理解场景

### 4. 验证结果
检查 AI 生成的结果，必要时进行修正

### 5. 记录流程
将成功的流程保存为模板，方便重复使用
